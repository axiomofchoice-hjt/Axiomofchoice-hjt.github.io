DeepSeek V4 等新一代 MoE 大模型，路由专家（Router Experts）的权重广泛采用 MXFP4 格式以压缩体积、降低访存。而很多硬件最低只支持 INT8 矩阵乘，没有 FP8/FP4 算力。若能在 INT8 硬件上模拟 MXFP4 矩阵乘，就能同时拿到 4-bit 权重的访存优势和 INT8 的算力优势。

MXFP4 数据以 FP4 存储，采用 Per-Block 量化：32 个数共享一个缩放因子，类型 FP8_ue8m0（8 位无符号指数），值恰为 2 的整数幂。

## 1. Per-Channel 量化

INT8 GEMM 依赖 Per-Channel 量化（一个通道共享一个缩放因子）：通道内缩放相同，就能先做纯整数累加（INT8 × INT8 → INT32），最后再转浮点乘缩放。Per-Block 量化每个 block 各自有缩放，累加中途就得转浮点，性能很差。所以核心问题是**把 Per-Block 量化改造成 Per-Channel 量化**。

## 2. 方案概述

FP4 的 16 个值乘以 16 恰好都能用 INT8 无损表示：

$$[0.0,\ 0.5,\ 1,\ 1.5,\ 2,\ 3,\ 4,\ 6,\ -0.0,\ -0.5,\ -1,\ -1.5,\ -2,\ -3,\ -4,\ -6] \times 16$$

$$=[0,\ 8,\ 16,\ 24,\ 32,\ 48,\ 64,\ 96,\ 0,\ -8,\ -16,\ -24,\ -32,\ -48,\ -64,\ -96]$$

于是用查表指令 TBL 把 4-bit FP4 映射成 INT8。又因 MXFP4 缩放因子是 2 的幂，统一 block 之间的缩放就是右移：各 block 权重右移对齐到同一尺度后跑 INT8 GEMM 累加，最后乘一个 Per-Channel 缩放因子。注意转换是**在线**的：权重以 MXFP4 存储，每个 block 都要先 TBL + 右移再喂给矩阵乘指令，两者交替出现。右移会丢精度，需要好的舍入。

## 3. 舍入处理

右移采用向最近 / 偶数舍入（Round to Nearest, Ties to Even）。设某 block 右移 $b$ 位，实际移 $b+1$ 位，多移的 1 位最后并入 Per-Channel 缩放乘 2 补回（浮点乘 2 几乎免费），目的是**把舍入压成最少的几条非矩阵乘指令**——转换与矩阵乘交替执行，这些指令会进内层循环。把移 $b+1$ 位拆成先移 $b$ 位、再移 1 位，后者有两种选择：

- 向下舍入：`(n >> b) >> 1`；
- 四舍五入：`((n >> b) + 1) >> 1`。

两者只在 `n >> b` 为奇数（即丢弃部分 $\ge 0.5$）时不同：大于 $0.5$ 时直接四舍五入即可，恰好 $0.5$（半值 tie）时才用 Ties to Even 取偶数邻居，此时少数 $(n, b)$ 组合需要 floor。关键观察：**对每个 FP4 取值 $n$，需要 floor 的 $b$ 至多只有一个**，因此可离线建一张 16 项表，记录每个取值需要 floor 的 $b$（记 $b_{\text{floor}}$，无则 $-1$）：

$$b_{\text{floor}} = [-1,\ 3,\ 4,\ -1,\ 5,\ -1,\ 6,\ -1,\ -1,\ -1,\ -1,\ 3,\ -1,\ 4,\ -1,\ 5]$$

运行时过程：`m = n >> b`；查表若 `b != b_floor[n]` 则 `m += 1`；再 `m >> 1`。

```cpp
const int8_t fp4_to_int8[16] = {
    0,  8, 16, 24, 32, 48, 64, 96,
    0, -8,-16,-24,-32,-48,-64,-96};
const int b_floor[16] = {
    -1, 3, 4, -1, 5, -1, 6, -1,
    -1,-1,-1, 3,-1, 4,-1, 5};

int8_t shift_weight(unsigned fp4, int b) {
    int m = fp4_to_int8[fp4] >> b;      // 右移 Per-Block 位数
    if (b != b_floor[fp4]) ++m;         // 否则四舍五入（m 为偶数时无效）
    return static_cast<int8_t>(m >> 1); // 再移 1 位，×2 留到累加后补
}
```

## 4. 完整实施方案

预处理（离线做一次）把每个通道的 MXFP4 缩放因子拆成两部分：

- **Per-Block 右移位数** $b = e_{\max} - e_b \ge 0$：取通道内最大缩放因子 $2^{e_{\max}}$ 为基准，缩放因子都是 2 的幂，除法等价于指数相减。
- **Per-Channel 缩放因子** $2^{e_{\max}}$：通道内唯一，留给最后浮点缩放。

权重不预先转换：推理时每个 block 在线做 TBL + 带舍入右移，与 INT8 GEMM 指令交替执行，累加结束后乘以 Per-Channel 缩放因子（再乘 2）即得浮点输出。
