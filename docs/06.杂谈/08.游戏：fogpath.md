雾之径 Fog Path 游戏概述。

游戏仍在开发中……

## 1. 简介

一款纯文本、轻度 Roguelike 的“搜打撤”（搜索、战斗、撤离）回合制冒险游戏。你以村庄为基地，一次次踏入随机生成的迷雾地牢，在搜刮、拼刀与撤退的循环中战斗、拾取、成长。成长完全来自装备与物品，没有角色等级。

## 2. 地牢

地牢由随机房间构成，撤离后即废弃，下次进入时将重新生成。小怪、Boss 与宝箱散布其中。

你可以随时撤离。

受魔素梯度影响，魔法装备一旦离开地牢就会永久失效，普通装备则不受影响。不过，失效的魔法装备依然可以兑换金币。

死亡惩罚：你将失去身上穿戴的全部装备，但背包不会丢失。忠实的宠物会把背包运回村庄，可惜它无法脱下你身上的东西。

## 3. 战斗

游戏采用同时出招的回合制。

每回合，你可以选择各类攻击、各类防御、休息或使用道具。攻击与防御都需要消耗法力；休息和法力药水则可以回复法力。

若双方都选择攻击，攻击的“动量”将正面相撞。动量高的一方直接命中，动量低的一方被完全压制、攻击全数格挡（赢家通吃）；动量相同时，双方攻击均被格挡。

基于这个机制，低伤害、高动量的攻击能有效化解敌人的攻势；而高伤害、低动量的攻击，则不妨趁敌人蓄力时发动，将伤害最大化。

部分攻击具有特殊效果：例如易损会让目标下回合受到的伤害翻倍；致盲会让目标下回合的攻击虽参与对撞却无法造成伤害或效果。防御的效果则包括减伤、反弹等。

怪物拥有多套固定的行为模式。执行完一个模式后，它会从模式池中随机抽取下一个模式。例如，哥布林可能使用「蓄力 → 普通攻击」或「蓄力 → 蓄力 → 重击」的模式。当它连续蓄力两次，你便能推理出下一次必然是重击。

## 4. 总结

《雾之径》是一款将“搜打撤”化为智识博弈的游戏：在“打”中解读怪物模式、以动量拼刀周旋；在“搜”中权衡魔法爆发的快感与永久收获的实在；在“撤”中时刻与自己的贪婪对赌。它的核心乐趣，正在于每一个回合的智识交锋，以及每一次穿越迷雾时，那股“再多走一步”的紧张与诱惑。
